# React Real Estate

A front-end application built with React and Vite, demonstrating real estate company property listings, filtering, and UI for browsing real estate offers.

## Tech Stack

- **Frontend**: React + Vite  
- **Styling**: CSS 
- **Routing**: React Router 
- **Linting / Code Quality**: ESLint, Prettier  
- **Build / Dev Tools**: Vite, VS Code  


## Getting Started

• Make sure you have the following installed:

- Node.js (v14+ or latest LTS recommended)  
- npm 

### Installation

• Clone the repo
git clone https://github.com/ImranS17/React-Real-Estate.git

• Move into the project directory
cd React-Real-Estate

• Install dependencies
npm install
